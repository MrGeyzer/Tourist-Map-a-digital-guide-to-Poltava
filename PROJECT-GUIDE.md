# Коротко про проєкт «Полтава поруч»

Це папка з повним кодом і матеріалами туристичної карти Полтави. Її можна відкрити в Провіднику, показати команді або скопіювати на інший комп’ютер.

## Як запустити

Публікація на GitHub Pages, локальна робота без публікації та перенесення на хостинг описані в [PUBLISHING.md](PUBLISHING.md). Батнік `prepare-publish.bat` перевіряє сайт і створює готову папку `dist` та архів `release/poltava-map.zip`. Публікація в GitHub Actions запускається вручну.

- На цьому комп’ютері двічі клацни `start-map.bat`.
- Щоб відкрити карту на телефоні в тій самій Wi-Fi мережі, двічі клацни `start-map-phone.bat` і введи адресу, яку покаже вікно.
- Не відкривай `index.html` подвійним клацанням: карта читає локальні GeoJSON-файли, тому їй потрібен локальний вебсервер.

## Де код

- `index.html` — інтерфейс, стилі та JavaScript-логіка карти: пошук, фільтри, фото, укриття, межа міста й перемикач панелі.
- `scripts/serve-map.mjs` — локальний вебсервер на Node.js, який подає сторінку та файли з цієї папки.
- `start-map.bat` і `start-map-phone.bat` — файли запуску карти на комп’ютері й телефоні.
- `PROJECT-GUIDE.md` — цей короткий опис; `README.md` містить технічні подробиці та джерела даних.

## Дані

- `data/poltava-poi.geojson` — точки туристичних об’єктів OpenStreetMap.
- `data/poltava-recreation.geojson` — зони відпочинку, дитячі майданчики, зелені зони й парки OpenStreetMap; оновлення — `node scripts/build-recreation.mjs`.
- `data/poltava-boundary.geojson` — контур міста, який малюється на карті.
- `data/poltava-shelters.geojson` — точки укриттів; `data/shelters-source.xlsx` — початковий набір міськради; `data/shelters-geocode-report.csv` — адреси, які не вдалося прив’язати.
- `data/wikimedia-images.json` і `data/wikimedia/` — справжні мініатюри з Wikimedia Commons із зазначеними авторами, ліцензіями та сторінками файлів. Для місць без підтвердженого фото картинка не підставляється.

## Технології

HTML, CSS і JavaScript; MapLibre GL JS для карти; GeoJSON для точок та меж; Node.js або Python для локального запуску. Серверної бази даних немає. Підкладка карти завантажується з інтернету.

## Що показати під час презентації

1. Контур Полтави та згруповані туристичні точки.
2. Пошук, фільтри й кнопку згортання панелі.
3. Блок «Відпочинок надворі»: вибір майданчиків, зон відпочинку, зелених зон або парків із лічильниками та завантаженням відкритого GeoJSON.
4. Картку пам’ятки з фото Wikimedia та посиланням на автора й ліцензію.
5. Перемикач шару укриттів і картку укриття.

Фотографії не генерувалися: показуються лише файли, пов’язані з об’єктами у Wikimedia/Wikidata або звірені за назвою та близькими координатами в Commons.

## «Без бар’єрів» і межі міста

Карта, геолокація та маршрути працюють у точному контурі міста Полтави. Режим «Без бар’єрів» біля пошуку використовує локальний кеш; під час перемикання фільтрів зовнішні джерела не запитуються. Деталі джерел, перевірок та імпорту ЛУН: [ACCESSIBILITY.md](ACCESSIBILITY.md).

- `scripts/accessibility-core.mjs` — модель, AND-фільтр, зіставлення та URL.
- `scripts/accessibility-ui.mjs` — перемикач, незалежні ознаки й картки.
- `scripts/build-accessibility.mjs` — побудова кешу з перевірених джерел.
- `scripts/accessibility-import.mjs`, `scripts/import-accessibility.mjs` — адаптер майбутнього ліцензованого експорту.
- `data/poltava-accessibility.geojson` — дані з походженням кожного твердження.
- `data/accessibility-source-audit.json` — доступність джерел, реальні поля, умови використання та звіт зіставлення.
